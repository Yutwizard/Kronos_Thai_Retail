1. Daily Quick-Scan

Objective: sanity-check whatever 10 tickers land in today's get_top_ranked(10) output against real news, using sources already pre-filtered by §4-§6 — this is a skim of what's already there, not research from scratch.

When: fold into the existing evening pipeline routine (~23:45 BKK), after the Trade Ticket is generated and before recording any paper trades. Time: 10-15 minutes.

Step 1.1
Pull today's top-10

Open the dashboard's Trade Ticket (or run get_top_ranked(10) directly) and note the 10 tickers for tonight's scan.

Step 1.2
Skim the Inoreader folders, per ticker

For each of the 10 tickers, check whichever Inoreader folder applies (Thai-market or DR-underlyings, set up per §6) for anything new since yesterday, filtered to that ticker's name.

Step 1.3
Check the Settrade App favorites (SET names only)

Glance at the Settrade App's push notifications for anything Inoreader missed — SET Group's own per-ticker channel (§6), covers SET-listed names only, not DR underlyings.

Step 1.4
Cross-check against the skip list

For anything flagged in Steps 1.2-1.3, check it against the fixed 5-item skip list in §3.

Only those five ever trigger a skip — routine earnings misses, analyst rating changes, guidance revisions, ordinary management reshuffles, and mechanical DR ratio/conversion notices are informational only and don't block the trade.
Step 1.5
One combined macro glance

Not per-ticker — a single check: SET index level/direction, USD/THB, and whether BoT released anything today. Pairs with the Nikkei Asia feed in the Inoreader macro folder (§6) if you want regional context too.

Step 1.6
Log the day's entry

Append to data/positions/morning_log.md (the same daily journal the paper-trading flow already writes to — see morning-paper-trading-guide.md Step 9).

News scan: no flags found across today's top-10.

Even a "no flags found" day gets a line, so there's a trace the scan actually happened. If a red flag did fire and you skipped a trade because of it, log it per §3's phrasing convention.

2. Weekly Deeper Review

Objective: broader sector and macro context that the daily quick-scan intentionally skips, plus a deeper one-time look at any name newly entering the top-10.

When: piggybacked onto the existing "3. Weekly Portfolio Review (15-20 minutes)" slot in operations-manual.html — every Sunday evening or Monday morning before market open. Not a separate standalone cadence. Time: 15-20 minutes.

Step 2.1
Sector context

For whichever SECTOR buckets (per kth/data/universe.py) the current top-10 touches, skim for sector-wide news beyond what the daily per-ticker scan caught.

Step 2.2
Past week's macro releases

Review the week's Bank of Thailand releases and any Thai SEC items (§4) that the daily glance (Step 1.5) wouldn't have surfaced in depth.

Step 2.3
SET Market Alerts check

Check SET Market Alerts for any name that's been sitting in the top-10 across multiple days — catches a structural flag (halt, caution list, cash-balance designation) that might have been missed day-to-day.

Step 2.4
New-entrant deep look

For any ticker newly entering the top-10 for the first time in a while, do one deeper pass: its IR page (§4/§5), recent filings, and — for a DR name — a check of the KTB/BLS DR-mechanics page (§5).

This is the "event-triggered" component of the weekly review, folded into the calendar cadence rather than run as a separate always-on watcher.

3. Red-Flag Decision Protocol

Trigger threshold

A red flag can come from either a primary source or a reputable secondary source (§4/§5's tiered lists) — you don't need to wait for primary-source confirmation before acting. Primary disclosure feeds are often slow or non-existent (SET's own RSS is dead; Nasdaq Copenhagen's feed isn't company-filterable), so a same-day secondary-press report is often the only realistic signal you'll get before market open.

The fixed skip list

Only these five trigger a skip. Everything else — routine earnings misses/beats, analyst rating changes, guidance revisions, ordinary management reshuffles, mechanical DR ratio/conversion notices — is informational only.

#TriggerWhere it typically shows up
1Trading halt / suspensionSET Market Alerts; home-exchange equivalent for DR names
2Cash-balance-only or caution-list designationSET Market Alerts
3Fraud allegation or regulatory investigation/enforcement actionThai SEC, AMF, CONSOB, or SEC EDGAR enforcement item
4Auditor's qualified opinion, disclaimer, or going-concern flagCompany IR / annual filing coverage
5Sudden, unscheduled C-suite departureCompany IR, primary/secondary press (not a scheduled transition)

Scope

Strictly single-ticker. A red flag skips only the flagged name's trade — this protocol does not add a macro-level override. The dashboard's existing Market State/Turmoil gate already handles systemic days, and CLAUDE.md already retracted manually overriding allocation based on a perceived SET macro regime (the regime-conditional-alpha decision). This protocol deliberately doesn't reintroduce that pattern via a news-driven back door.

DR-specific addition

For DR trades, also check the KTB/BLS issuer-page DR-mechanics channel (§5) — a ratio/conversion event severe enough to pair with a trading-halt-equivalent triggers a skip even if nothing shows up in the underlying's home-market news, since this failure mode has no equivalent on the Paris/Milan/Copenhagen side.

Recording the override

Log it in the existing data/positions/morning_log.md Reason field, using a consistent phrasing convention:

Reason: Manual override — news red flag ([trigger type], [source]).
No new field, no dashboard/API change — this reuses infrastructure that already exists.

6. One-Time Aggregation Setup

Full research trail: .scratch/news-monitoring-template/research/03-alerting-tooling-findings.md. Since both universes (52 tickers, 6 DR underlyings) are fixed lists, this is a one-time setup, not daily reconfiguration.

Setup 1
Create a free Inoreader account

150 RSS feeds + 20 email-to-RSS "Newsletter Feeds" on the free tier — chosen over Feedly, whose free tier excludes newsletters.

Setup 2-3
"Thai-market" folder

Add SETTRADE's 6 RSS feeds (settrade.com/th/rss). Then, for each of the 52 thai_equity/thai_index tickers, add a Google News RSS search feed:

https://news.google.com/rss/search?q="TICKER.BK"+"Company Name"
Always include the full company name in the query, not just the ticker — a bare-ticker query returns stale, years-old results. For names whose English name collides with a common word, add a disambiguating News/Finance-only phrasing.
Setup 4-6
"DR-underlyings" folder

Add all 6 Seeking Alpha per-symbol feeds (§5) — no signup needed, just add the URLs. Then create an Inoreader Newsletter Feed for each DR-underlying company that offers an email-alert signup (confirmed for Sanofi and Novo Nordisk; check Hermès/L'Oréal/LVMH/Ferrari too) and subscribe using the generated address. Finally, add 6 Google News RSS search feeds for the underlying names — Ferrari needs a disambiguator (pair with "RACE.MI"), L'Oréal needs both spellings (L'Oréal / L'Oreal).

Setup 7
Optional macro addition

Add Nikkei Asia's RSS (asia.nikkei.com/rss/feed/nar) to a macro/regional folder — personal, non-commercial use only per its terms.

Setup 8
Separately, install the Settrade App

Add all 52 thai_equity/thai_index tickers to its Favorites list for push notifications.

This is SET Group's own per-ticker channel and the only piece that stays outside Inoreader — no RSS/email export exists for it.

Daily habit

Open Inoreader, filter to unread items across both folders, cross-reference against today's get_top_ranked(10) output — skim only the items touching today's top-10 names (§1) — then separately glance at the Settrade App's notifications for the same names.
